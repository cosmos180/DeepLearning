# 📝 格式变更说明

## 变更概述

IP 地址管理系统的数据格式已更新，现在支持 IP 地址 + 标识符的格式。

## 旧格式 vs 新格式

### 旧格式
```
# IP 地址列表
# 每行一个 IP 地址
# 示例: 192.168.1.1

127.0.0.1
192.168.1.1
10.0.0.1
```

### 新格式
```
# IP 地址列表
# 格式: IP地址 标识符
# 示例: 192.168.1.1 rt2

10.100.35.150 rt2
10.100.35.151 rt2
10.100.35.152 rt2
```

## 变更内容

### 1. 数据文件格式
- **新增**: 每行 IP 地址后添加标识符（默认为 `rt2`）
- **格式**: `IP地址 标识符`
- **示例**: `10.100.35.150 rt2`

### 2. 后端逻辑
- **解析**: 能够读取和解析带标识符的行
- **写入**: 新增 IP 时自动添加默认标识符
- **删除**: 删除时正确匹配 IP 地址部分
- **兼容性**: 支持纯 IP 地址格式（自动添加默认标识符）

### 3. 前端界面
- **显示**: 只显示 IP 地址，隐藏标识符
- **用户操作**: 用户无需关心标识符的存在
- **API**: API 返回的数据中包含完整的格式信息

### 4. 用户操作
- **添加**: 用户输入 IP 地址即可，系统自动添加标识符
- **删除**: 用户选择 IP 地址删除，系统正确处理完整格式
- **查看**: 用户只看到 IP 地址，标识符在后台处理

## 技术实现

### 后端新增方法

1. **`_parse_ip_line(line: str)`**
   - 解析文件行，返回 `(ip, identifier)` 元组
   - 支持两种格式：`IP` 和 `IP 标识符`

2. **`_format_ip_line(ip: str, identifier: str)`**
   - 格式化 IP 行为文件格式
   - 自动添加默认标识符

3. **`_get_default_identifier()`**
   - 返回默认标识符 `rt2`
