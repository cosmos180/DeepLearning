# DeepLearning Repository

This is a multi-language learning and practice repository that includes:

## Languages and Projects

### Deep Learning
- PyTorch MNIST examples
- Image processing utilities
- Deep learning implementations in Python

### Multiple Language Implementations
- Android/Java
- C++ (jason library implementation)
- Go (kibana log processing and music player)
- Kotlin
- Node.js (cosine similarity calculation)
- Python
- Rust

### Tools and Scripts
- Shell scripts including ffmpeg multi-process processing

## Project Structure

### C++ Jason Library
Located in `cpp/jason/`, includes:
- JSON parser
- Network components
- Coroutines
- Bitmap counter
- Cache implementation
- Smart pointer and modern C++ features

### Go Projects
- Kibana log processing (with protobuf definitions)
- Music player implementation
- CGO examples

## Getting Started
1. Clone the repository
2. Choose the project you want to work with
3. Follow the README in each project directory for specific instructions
