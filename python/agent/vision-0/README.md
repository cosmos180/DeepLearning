为了方便后续进行 Prompt Engineering（提示词工程）或搭建多智能体（Multi-Agent）系统，将构想标准化为一套**“AI 影视制片厂”**的职能手册。

这份清单明确了每个 Agent 的**输入（Input）**、**核心任务（Tasks）**和**标准输出（Output）**。

---

## 📽️ AI 影视全流程智能体标准化定义

### 1. 原著作者 Agent (The Creator)

* **角色定位：** 创意源头与世界观架构师。
* **核心任务：** * 将模糊的创意（Seeds）转化为具备商业潜力的主题（Themes）。
* 构建“故事圣经”：包含世界观设定、角色传记、人物关系网。


* **标准输出：**
* **Logline：** 一句话梗概（核心冲突+主角+目标）。
* **Character Sheets：** 角色视觉特征（方便后续生成模型）与性格动机。
* **Beat Sheet：** 故事节拍表（关键剧情转折点）。



### 2. 编剧 Agent (The Screenwriter)

* **角色定位：** 文字蓝图的绘制者，负责叙事节奏。
* **核心任务：**
* 将大纲转化为**标准剧本格式**（Scene Headings, Action, Dialogue）。
* 优化对话：确保台词符合角色性格，消除“AI 味”。
* 结构控制：确保 1 小时视频的起承转合符合戏剧结构（如三幕式结构）。


* **标准输出：** * **Final Script：** 标注了场景、时间、人物对话和动作描述的完整剧本。

### 3. 导演 Agent (The Director)

* **角色定位：** 视觉翻译官与审美决策者。
* **核心任务：**
* **分镜拆解：** 将剧本文字拆解为具体的镜头语言（景别、角度、运动）。
* **Prompt 转化：** 为图像/视频生成模型（如 Sora, Veo）编写视觉描述词。
* **审美统一：** 监督画面风格（Color Grade）是否符合全片基调。


* **标准输出：** * **Shot List：** 镜头清单（机位图、构图要求、光影氛围）。

### 4. 艺术总监 Agent (Art Director / Production Designer)

* **角色定位：** 视觉风格的“守门人”。
* **核心任务：**
* 定义全局色彩方案（Palette）。
* 生成并锁定角色和场景的**参考图（Reference Sheets）**，确保跨镜头的一致性。


* **标准输出：** * **Style Guide：** 包含材质、灯光、服装风格的视觉标准手册。

### 5. 剪辑与后期 Agent (Editor & Sound Designer)

* **角色定位：** 节奏把控与声画合一。
* **核心任务：**
* **素材拼合：** 根据剧本节奏对生成的视频片段进行逻辑排序。
* **声效合成：** 调用 Lyria 等模型生成配乐，并进行环境音（SFX）填充。


* **标准输出：** * **Timeline Report：** 剪辑时间轴说明及成片逻辑索引。

### 🚀 协作流程概览

| 阶段 | 主导 Agent | 交付物 |
| --- | --- | --- |
| **开发期** | 原著作者 | 故事大纲 + 角色设定 |
| **创作期** | 编剧 | 标准剧本 (Script) |
| **筹备期** | 导演 + 艺术总监 | 分镜清单 + 视觉参考手册 |
| **制作期** | 视频生成模型 (如 Veo) | 原始视频素材片段 |
| **后期期** | 剪辑与后期 | 最终成片 (1小时视频) |
