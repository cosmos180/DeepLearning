# 女频古言·大漠商战 · 故事梗概

---

*决定：* 结合 #1（经济战/垄断）、#6（围城/生存）和 #2（情报网/马甲）

*理由：*
- 具体高风险目标：生存与复国
- 逻辑闭环下的智性爽感：用经济手段解决军事问题
- 极致拉扯：男主从敌人/征服者被女主才智吸引

---

**书名**： 《金锁孤城》

**核心设定**：

*女主*：流亡公主，穿越自带现代经济学知识
*男主*：敌国战神将军，围城统帅
*关系*：征服者与亡国奴 → 对手 → 合作 → 情感

**主线剧情**：

*开篇*：国破，女主困守孤城，男主率十万大军围城
*转折*：女主垄断城内所有资源，用现代经济手段运作
*高潮*：敌军被迫向女主购买粮草，女主用经济战瓦解围城
*掉马*：女主身份暴露，男主发现她就是自己要找的流亡公主
*终局*：男主倒戈，两人联手复国

**核心爽点**：

- 以商止战：不费一兵一卒买退十万大军
- 智性博弈：女主用经济手段碾压军事力量
- 极致拉扯：男主从征服者到裙下臣
- 马甲掉落：身份反差带来的戏剧张力

**金手指**：

- 现代经济学：垄断、期货、货币战
- 情报网：掌控西域商贸信息
- 过目不忘：账房能力，找出贪腐证据

**冲突设计**：

*外部*：围城生存、资源争夺、敌国压力
*内部*：杀父之仇（待确认）、身份认同、情感拉扯
*理念*：女主用商道破男主兵道
