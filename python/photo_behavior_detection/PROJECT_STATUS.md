## 一、项目概述

### 1.1 项目目标
开发一套基于计算机视觉的智能行为分析系统，实时检测并识别用户使用手机、相机等设备进行拍照或录制的行为。

### 1.2 目标应用场景
| 场景 | 优先级 | 核心需求 |
|------|--------|----------|
| 考场监考 | P0 | 高准确性、证据链完整 |
| 影院/博物馆防盗拍 | P1 | 成本敏感、大规模部署 |
| 企业保密区域监控 | P0 | 高精度、系统集成 |
| 智能驾驶辅助 | P2 | 实时性、嵌入式部署 |

**技术栈确定**：
| 模块 | 技术 | 理由 |
|------|------|------|
| 设备检测 | YOLOv8-M / YOLOv10-B | 速度与精度平衡 |
| 姿态估计 | MediaPipe Pose | 轻量、跨平台、33关键点 |
| 动作识别 | LSTM + Attention | 时序建模能力强 |
| 融合引擎 | 神经网络 + 规则 + HMM | 多模态融合 |

## 三、技术架构概览

### 3.1 系统流程图

```
┌─────────────────────────────────────────────────────────────┐
│                    视频输入 (RTSP/USB/文件)                    │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              阶段1: 快速筛查 (YOLOv8-Nano)                    │
│         • 人员和设备检测                                       │
│         • ROI区域选择                                         │
└────────────────────┬────────────────────────────────────────┘
                     │ 疑似区域
                     ▼
┌─────────────────────────────────────────────────────────────┐
│           阶段2: 精细分析 (多模型并行推理)                     │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ 姿态估计     │  │ 设备检测     │  │ 动作识别     │      │
│  │(MediaPipe)   │  │(YOLOv8-M)    │  │(LSTM+Attn)   │      │
│  │• 手臂角度    │  │• 设备分类    │  │• 时序模式    │      │
│  │• 持握姿势    │  │• 置信度      │  │• 动作分类    │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              阶段3: 融合决策                                  │
│  • 神经网络融合 (Cross-attention + Self-attention)           │
│  • 规则融合 (贝叶斯概率 + 空间一致性检查)                     │
│  • 时序平滑 (隐马尔可夫模型HMM)                              │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                    输出 (告警/日志/可视化)                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 融合规则

| 规则 | 条件 | 权重调整 |
|------|------|----------|
| 设备-手部关联 | 设备必须在手部附近 | 不满足×0.1 |
| 手臂举起 | 手臂角度 > 45° | 不满足×0.3 |
| 闪光灯检测 | 检测到闪光灯 | 满足×1.5 |
| 录制稳定性 | 录制需要更高身体稳定性 | 专门阈值 |

### 5.2 标注层级

```
层级1: 目标检测标注 (COCO/YOLO格式)
├── person (人)
├── smartphone (智能手机)
├── camera (相机)
├── tablet (平板)
└── recording_device (录制设备)

层级2: 姿态标注
├── MediaPipe 33点关键点
└── 人工修正关键点

层级3: 行为标注
├── no_action (无拍照行为)
├── taking_photo (拍照行为)
├── recording_video (录制视频)
├── viewing_device (查看设备，负样本)
└── calling_phone (打电话，负样本)

层级4: 属性标注
├── device_orientation: horizontal/vertical
├── holding_style: single_hand/double_hands
├── position: standing/sitting/walking
└── camera_angle: front/side/back
```

## 七、风险与挑战

### 7.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 检测准确率不达标 | 高 | 增加训练数据、模型集成 |
| 边缘设备性能不足 | 高 | 模型量化、硬件升级 |
| 实时性要求无法满足 | 高 | 异步处理、模型优化 |
| 复杂场景误报高 | 中 | 场景自适应、规则优化 |

### 7.2 伦理与隐私

- **数据脱敏**：训练数据去除人脸、敏感信息
- **边缘处理**：视频在本地处理，不上传云端
- **最小化采集**：仅采集必要的检测框和元数据
- **存储加密**：敏感数据加密存储
