# 功能需求文档

## 1. 功能概述

本文档定义"账单通"1.0 MVP版本的功能需求。MVP版本聚焦于核心的**消费记录**和**数据可视化**功能，确保产品快速上线并验证核心价值。

---

## 2. 功能模块架构

账单通 (BillTrack)
├── 消费记录模块

## 3. 核心功能详细需求

### 3.1 消费记录模块

#### 3.1.1 快速记账 (P0 - 核心功能)

**功能描述**：
用户可以通过简单快速的方式记录一笔消费，这是产品最重要的功能。

**用户故事**：
- 作为一名用户，我希望能在3秒内完成一笔消费记录，这样我才愿意坚持记账
- 作为一名用户，我希望记录时只需要输入必要信息，这样操作才足够简单

**输入要素**：
| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| 金额 | 数字 | 是 | 消费金额，支持小数点后2位 | 28.50 |
| 分类 | 选择 | 是 | 从预设或自定义分类中选择 | 餐饮-午餐 |
| 日期 | 日期 | 是 | 默认当前时间，可修改 | 2025-01-16 |
| 备注 | 文本 | 否 | 可选，最长50字 | 麦当劳套餐 |
| 支付方式 | 选择 | 否 | 可选，默认上次选择 | 微信支付 |

**交互流程**：
1. 用户点击主页面"+"按钮或摇一摇手机
2. 弹出快速记账对话框
3. 输入金额（默认弹出数字键盘）
4. 选择分类（显示常用分类，支持搜索）
5. 确认保存（自动完成）

**界面要求**：
- 金额输入框：大字体、居中显示
- 分类选择：图标+文字，支持左右滑动
- 保存按钮：显著、易点击
- 支持手势操作：下滑关闭

**验收标准**：
- 新手用户能在5秒内完成首次记录
- 老用户能在3秒内完成记录
- 输入错误时有明确提示
- 保存成功后有触觉/视觉反馈

#### 3.1.2 记录管理 (P0 - 核心功能)

**功能描述**：
用户可以查看、编辑、删除已有的消费记录。

**用户故事**：
- 作为一名用户，我希望能够查看历史记录，这样我可以确认之前的记录
- 作为一名用户，我希望能够修改错误的记录，这样我的数据才准确

**功能点**：
1. **记录列表**
   - 按时间倒序展示所有记录
   - 显示：日期、金额、分类、备注
   - 支持按日期分组显示
   - 支持下拉刷新、上拉加载更多

2. **记录详情**
   - 点击记录查看完整信息
   - 显示所有字段内容
   - 显示创建时间、修改时间

3. **记录编辑**
   - 支持修改所有字段
   - 保存时更新修改时间

4. **记录删除**
   - 单条删除：带二次确认
   - 删除后不可恢复（MVP版本）
   - 删除成功后列表自动刷新

**界面要求**：
- 列表项：左侧图标，中间文字，右侧金额
- 金额颜色：支出显示红色，收入显示绿色
- 空状态：无记录时显示引导文案

**验收标准**：
- 列表加载速度 < 500ms
- 编辑保存成功后立即更新列表
- 删除操作有明确确认提示

---

#### 3.1.3 批量操作 (P1 - 重要功能)

**功能描述**：
用户可以批量删除多条记录（主要用于清理测试数据或批量修改）。

**用户故事**：
- 作为一名用户，我希望能够批量删除多条记录，这样清理数据更方便

**功能点**：
1. **批量选择模式**
   - 长按进入选择模式
   - 点击选择/取消选择
   - 全选/取消全选

2. **批量删除**
   - 显示已选择数量
   - 删除前二次确认
   - 显示删除进度

**验收标准**：
- 批量操作时界面不卡顿
- 删除过程中显示进度提示

#### 3.2.2 自定义分类 (P0 - 核心功能)

**功能描述**：
用户可以创建、编辑、删除自己的分类。

**用户故事**：
- 作为一名用户，我希望能够添加自己的分类，这样分类更符合我的习惯

**功能点**：
1. **创建分类**
   - 输入分类名称（1-10字）
   - 选择父级分类（可选）
   - 选择图标和颜色
   - 保存时验证名称重复

2. **编辑分类**
   - 修改名称、图标、颜色
   - 已使用的分类也可以编辑

3. **删除分类**
   - 未使用的分类：直接删除
   - 已使用的分类：
     - 提示该分类下有多少条记录
     - 询问是否转移到"其他"分类
     - 确认后执行转移并删除

**界面要求**：
- 分类管理页面：列表展示所有分类
- 支持拖拽排序
- 显示每个分类的使用次数

**验收标准**：
- 自定义分类数量上限：50个
- 分类名称支持特殊字符过滤
- 删除操作有明确提示

---

#### 3.2.3 分类规则 (P2 - 后续版本)

**功能描述**：
为分类设置规则，实现自动分类（未来版本）。

**示例规则**：
- 备注包含"麦当劳"、"肯德基" → 自动分类为"餐饮-快餐"
- 备注包含"滴滴" → 自动分类为"交通-打车"
- 金额 < 10元且时间在 7:00-9:00 → 建议分类为"餐饮-早餐"

### 3.3 数据统计模块

#### 3.3.1 统计概览 (P0 - 核心功能)

**功能描述**：
在首页展示核心统计数据，让用户快速了解自己的消费情况。

**展示指标**：
1. **本月支出**
   - 显示：本月总支出金额
   - 对比：与上月相比的增长/减少百分比
   - 预算：本月预算使用率（如果设置了预算）

2. **今日支出**
   - 显示：今天的总支出
   - 对比：与昨日对比

3. **本周支出**
   - 显示：本周总支出
   - 对比：与上周对比

4. **分类排行**
   - 显示：支出最多的前3个分类
   - 格式：图标 + 分类名 + 金额

5. **最近记录**
   - 显示：最近3-5条记录
   - 支持快速查看更多

**界面要求**：
- 卡片式布局
- 重要数字大字体显示
- 使用颜色区分增长/减少
- 支持左右滑动切换月份

**验收标准**：
- 统计数据实时更新
- 切换月份时平滑过渡
- 数据为0时有友好提示

---

#### 3.3.2 趋势分析 (P1 - 重要功能)

**功能描述**：
通过图表展示消费趋势，帮助用户发现消费规律。

**用户故事**：
- 作为一名用户，我希望看到消费趋势图，这样我能了解自己的消费变化

**功能点**：
1. **日/周/月切换**
   - 日视图：近30天每日支出
   - 周视图：近12周每周支出
   - 月视图：近12个月每月支出

2. **图表交互**
   - 点击数据点查看详细信息
   - 支持缩放（双指捏合）
   - 支持拖动查看历史数据

3. **对比分析**
   - 与上期对比（日vs日，周vs周，月vs月）
   - 显示增长/减少金额和百分比
   - 高亮显示最高/最低点

**图表类型**：
- 折线图：展示趋势变化
- 柱状图：展示对比数据

**界面要求**：
- 图表清晰易读
- 颜色使用符合直觉
- 支持横屏查看（移动端）

**验收标准**：
- 图表渲染流畅
- 数据准确无误
- 交互响应及时

---

#### 3.3.3 分类占比 (P0 - 核心功能)

**功能描述**：
展示各分类的支出占比，帮助用户了解消费结构。

**用户故事**：
- 作为一名用户，我希望看到饼图或环形图，这样我能知道钱都花在哪些方面

**功能点**：
1. **饼图/环形图展示**
   - 显示一级分类的占比
   - 点击分类查看二级分类占比
   - 支持时间范围选择（日/周/月/年）

2. **分类详情**
   - 点击饼图区块查看详情
   - 显示：分类名称、金额、占比、记录数
   - 支持钻取查看该分类的所有记录

3. **列表视图**
   - 按金额排序展示所有分类
   - 显示：图标、名称、金额、占比、进度条
   - 支持点击查看详情

**界面要求**：
- 饼图使用清晰的配色
- 避免太多小分类导致图表混乱
- 提供图例说明

**验收标准**：
- 占比计算准确
- 图表渲染速度快
- 分类点击响应灵敏

### 3.4 用户设置模块

#### 3.4.1 基本设置 (P1 - 重要功能)

**功能描述**：
用户可以设置应用的基本偏好。

**设置项**：
1. **货币设置**
   - 支持货币：CNY（人民币）、USD（美元）、EUR（欧元）等
   - 默认：CNY
   - 显示格式：¥（或$、€）

2. **小数位数**
   - 选项：0位、1位、2位
   - 默认：2位

3. **每月开始日期**
   - 选项：1日、5日、10日、15日、20日、25日
   - 默认：1日
   - 影响：月度统计的计算周期

4. **主题设置**
   - 浅色模式（默认）
   - 深色模式
   - 跟随系统

5. **语言设置**
   - 简体中文（默认）
   - English（后续版本）

**验收标准**：
- 设置立即生效
- 货币符号显示正确
- 主题切换流畅

---

#### 3.4.2 预算管理 (P1 - 重要功能)

**功能描述**：
用户可以为每月设置总预算或分类预算，帮助控制支出。

**用户故事**：
- 作为一名用户，我希望设置每月预算，这样我能避免超支

**功能点**：
1. **总预算设置**
   - 输入每月总预算金额
   - 显示：已用预算 / 总预算（进度条）
   - 计算：本月支出 / 总预算 = 使用率

2. **分类预算**
   - 为每个一级分类设置预算
   - 显示：该分类已用 / 分类预算
   - 支持批量设置

3. **预算提醒**
   - 当使用率达到80%时：警告提示
   - 当使用率超过100%时：超支提示
   - 支持关闭提醒

**界面要求**：
- 预算进度条颜色：
  - < 50%：绿色
  - 50%-80%：黄色
  - 80%-100%：橙色
  - > 100%：红色

**验收标准**：
- 预算计算准确
- 提醒及时但不打扰
- 支持修改历史月份的预算

---

#### 3.4.3 数据管理 (P1 - 重要功能)

**功能描述**：
用户可以管理自己的数据，包括导出、备份、恢复。

**用户故事**：
- 作为一名用户，我希望导出数据到Excel，这样我可以在电脑上深度分析
- 作为一名用户，我希望备份和恢复数据，这样换手机时不丢失数据

**功能点**：
1. **数据导出**
   - 支持格式：CSV、Excel（.xlsx）
   - 导出内容：所有消费记录
   - 导出选项：选择时间范围、选择分类
   - 导出方式：分享到其他应用、保存到文件

2. **数据备份**
   - 备份格式：JSON
   - 备份内容：所有数据（记录、分类、设置）
   - 备份位置：本地文件、云存储（后续版本）

3. **数据恢复**
   - 从备份文件恢复
   - 恢复前警告：将覆盖当前数据
   - 恢复成功后重启应用

4. **数据清除**
   - 清除所有记录
   - 清除所有数据（包括设置）
   - 操作前二次确认并输入密码

**验收标准**：
- 导出数据格式正确
- 备份文件完整可用
- 恢复操作不丢失数据

### 3.5 系统模块

#### 3.5.1 用户引导 (P0 - 核心功能)

**功能描述**：
首次使用时展示产品功能介绍，帮助用户快速上手。

4. **首次记账引导**
   - 第一次点击"+"时：气泡提示
   - 引导完成第一笔记录

**界面要求**：
- 使用插图或动画
- 支持跳过引导
- 文案简洁明了

**验收标准**：
- 引导流程不超过1分钟
- 跳过后可以重新查看（设置中）

## 6. 数据模型设计

### 6.1 核心实体

#### 消费记录 (Expense)

```yaml
字段名              类型        说明                    约束
id                 String      唯一标识                主键，UUID
amount             Decimal     金额                    必须，>0
category_id        String      分类ID                  外键
date               DateTime    消费日期                必须
note               String      备注                    可选，max 50
payment_method     String      支付方式                可选
created_at         DateTime    创建时间                自动生成
updated_at         DateTime    修改时间                自动更新
```

#### 分类 (Category)

```yaml
字段名              类型        说明                    约束
id                 String      唯一标识                主键，UUID
name               String      分类名称                必须，unique
parent_id          String      父分类ID                可选，外键
icon               String      图标名称                必须
color              String      颜色值                  必须，HEX
is_custom          Boolean    是否自定义               默认false
sort_order         Integer    排序序号                默认0
created_at         DateTime    创建时间                自动生成
```

#### 预算 (Budget)

```yaml
字段名              类型        说明                    约束
id                 String      唯一标识                主键，UUID
category_id        String      分类ID                  可选，NULL表示总预算
amount             Decimal     预算金额                必须，>0
month              String      月份（YYYY-MM）         必须
created_at         DateTime    创建时间                自动生成
updated_at         DateTime    修改时间                自动更新
```

#### 用户设置 (UserSettings)

```yaml
字段名              类型        说明                    约束
id                 String      唯一标识                主键，UUID
currency           String      货币代码                默认CNY
decimal_places     Integer    小数位数                默认2
month_start_day    Integer    每月起始日期            默认1
theme              String      主题                    默认light
language           String      语言                    默认zh-CN
reminder_enabled   Boolean    是否启用提醒            默认true
reminder_time      String      提醒时间                默认21:00
```

## 7. 界面原型说明

### 7.1 主要页面清单

1. **启动页**：展示Logo和加载动画
2. **欢迎/引导页**：首次使用的功能介绍
3. **首页**：统计概览、快速记账入口
4. **记录列表页**：查看所有消费记录
5. **快速记账弹窗**：输入记录信息
6. **统计页**：图表、趋势、占比
7. **分类管理页**：管理所有分类
8. **设置页**：应用设置、数据管理
9. **搜索页**：搜索记录
10. **记录详情页**：查看单条记录详情

### 7.2 关键界面描述

#### 首页
- 顶部：本月支出卡片（大字显示金额）
- 中部：今日、本周、本月统计卡片
- 底部：最近记录列表（显示5条）
- 右下角：悬浮按钮"+"（快速记账）
- 底部导航栏：首页、统计、我的

#### 快速记账弹窗
- 金额输入框（大字体、居中）
- 分类选择（横向滚动的图标列表）
- 日期选择（默认今天）
- 备注输入（可选）
- 保存按钮（底部，大按钮）

#### 统计页
- 顶部：时间选择器（本月、上月、自定义）
- 中部：
  - 支出趋势折线图
  - 分类占比饼图
  - 分类排行列表
- 支持点击图表钻取详情
