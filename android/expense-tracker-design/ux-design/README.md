## 设计理念概览

### 核心设计哲学

**"减少认知负荷，让记账成为无意识习惯"**

三个核心支柱：
1. **极速交互**：3秒完成记录
2. **即时反馈**：每次操作都有明确反馈
3. **渐进披露**：根据熟练度逐步展示功能

### 心理学导向

所有设计基于以下心理学原理：

| 原理 | 应用 |
|------|------|
| Fitts定律 | 主要按钮置于拇指最佳区域 |
| 格式塔原则 | 相似元素分组，建立视觉关联 |
| 认知负荷理论 | 限制信息密度，使用渐进披露 |
| 操作性条件反射 | 即时反馈强化记账行为 |
| 损失厌恶 | 容错设计，降低犯错焦虑 |

## 设计系统速查

### 色彩系统

| 颜色 | 用途 | 色值 | 心理暗示 |
|------|------|------|----------|
| 主题色 | 主要操作、健康 | #4CAF50 | 成长、健康 |
| 错误色 | 支出、错误 | #FF5252 | 警觉、注意 |
| 警告色 | 预算警告 | #FFC107 | 注意 |
| 文字主色 | 标题 | #212121 | 清晰 |
| 文字次色 | 辅助 | #757575 | 次要 |

### 字体系统

| 用途 | 大小 | 字重 |
|------|------|------|
| 标题 | 24sp | Medium |
| 副标题 | 18sp | Medium |
| 正文 | 16sp | Regular |
| 辅助 | 14sp | Regular |
| 说明 | 12sp | Regular |

### 间距系统

基于8dp网格：8dp、16dp、24dp、32dp

### 交互规范

| 操作 | 目标时间 | 优化策略 |
|------|---------|---------|
| 应用启动 | <2秒 | 品牌动画+后台加载 |
| 快速记账 | <3秒 | 乐观UI更新 |
| 页面切换 | <300ms | 并行加载数据 |

## 可访问性标准

### WCAG 2.1 AA级合规

- 颜色对比度 ≥ 4.5:1
- 触控目标 ≥ 44x44dp
- 支持屏幕阅读器
- 支持键盘导航
- 支持字体缩放（100%-200%）
