# 账单通 (BillTrack) 页面原型规范

## 1. 页面原型概述

本文档详细定义账单通所有页面的布局、元素、交互和视觉规范，为设计和开发提供准确的参考。

---

## 2. 启动页 (Splash Screen)

### 2.1 页面描述

**用途**：品牌展示、应用初始化加载

**持续时间**：2秒（可中断）

### 2.2 布局规范

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│                                     │
│         ┌──────────┐               │
│         │          │               │
│         │   Logo   │   120x120dp   │
│         │          │               │
│         └──────────┘               │
│                                     │
│         账单通                      │ ← 24sp，粗体
│      BillTrack                     │ ← 14sp
│                                     │
│                                     │
│     ● ● ● ● ●                      │ ← 加载动画
│                                     │
│                                     │
└─────────────────────────────────────┘
```

### 2.3 元素规范

| 元素 | 规格 | 说明 |
|------|------|------|
| Logo | 120x120dp | 居中显示 |
| 应用名称 | 24sp，粗体 | 距离Logo 24dp |
| 英文名称 | 14sp，常规 | 距离中文 4dp |
| 加载动画 | 3个圆点 | 直径8dp，间距4dp |

### 2.4 动画效果

- Logo淡入：400ms
- 文字淡入：600ms（延迟200ms）
- 加载动画：循环缩放（1000ms/次）

**4页引导内容**：

| 页码 | 标题 | 插图描述 | 说明文字 |
