# 页面原型描述

## 1. 页面原型概述

本文档提供账单通所有主要页面的详细原型描述，结合心理学原理说明每个设计决策。

**原型格式**：
- ASCII文字布局图
- 交互说明
- 心理学设计要点
- 视觉规范

---

## 2. 启动页 (Splash Screen)

### 2.1 布局原型

```
┌─────────────────────────────┐
│                             │
│                             │
│                             │
│          [Logo]             │ ← 120x120dp, 居中
│                             │
│          账单通              │ ← 24sp, 主题色
│                             │
│                             │
│                             │
│                             │
│     ● ● ● ● ● (Loading)    │ ← 加载动画
│                             │
└─────────────────────────────┘
背景: 主题色 #4CAF50
```

### 2.2 交互规范

| 阶段 | 持续时间 | 视觉效果 |
|------|---------|---------|
| 淡入 | 300ms | Logo淡入 |
| 停留 | 1400ms | 加载动画 |
| 淡出 | 300ms | 整页淡出 |

### 2.3 心理学设计要点

**品牌建立**：
- Logo居中强化品牌记忆
- 主题色背景建立品牌联想
- 短暂停留营造期待感

**减少等待焦虑**：
- 加载动画提供系统工作证据
- 总时长<2秒，符合用户耐心阈值
- 数据准备好后可立即跳过

**探索引导**：
- "查看更多"链接引导深入
- 卡片可点击暗示更多信息
- FAB始终可见提醒功能

```
│  │  选择分类           │   │
│  │  ┌───┬───┬───┬───┐ │   │
│  │  │🍔 │🚇 │👕 │🎬 │ │   │ ← 分类选择
│  │  │餐饮│交通│购物│娱乐│ │   │
│  │  └───┴───┴───┴───┘ │   │
│  │  ┌───┬───┬───┬───┐ │   │
│  │  │🏠 │💊 │📚 │➕  │ │   │

│  │  └───┴───┴───┴───┘ │   │
│  ├─────────────────────┤   │
│  │  📅 今天 12:30  >   │   │ ← 日期选择
│  ├─────────────────────┤   │
│  │  ┌───────────────┐   │   │
│  │  │添加备注(可选) │   │   │ ← 备注输入
│  │  └───────────────┘   │   │
│  ├─────────────────────┤   │
│  │  💳 支付方式: 微信 > │   │ ← 支付方式
│  ├─────────────────────┤   │
│  │  ┌───────────────┐   │   │
│  │  │     保存       │   │   │ ← 保存按钮
│  │  └───────────────┘   │   │
│  └─────────────────────┘   │
└─────────────────────────────┘
```

### 5.2 交互流程

1. **打开**：从底部滑入，背景模糊
2. **输入金额**：弹出数字键盘，实时格式化
3. **选择分类**：点击分类，高亮确认
4. **修改日期**：可选，默认今天
5. **添加备注**：可选，最多50字
6. **保存**：验证通过后关闭

### 5.3 心理学设计要点

**聚焦注意力**：
- 背景模糊创建"专注模式"
- 金额输入居中且最大
- 减少干扰元素

**降低操作负担**：
- 默认值减少决策（今天、常用分类）
- 自动格式化减少输入错误
- 可选字段明确标注

**即时确认**：
- 选中分类立即高亮
- 金额实时格式化
- 保存后震动+Toast反馈

### 10.2 心理学设计要点

- 输入时即时过滤
- 关键词高亮显示
- 结果数量提示

**空状态友好**：
- 无结果时提供建议
- 清除历史快捷入口
- 返回路径明确

## 11. 响应式适配

### 11.1 小屏幕适配 (4.7"-5.5")

**调整策略**：
- 减少内边距（24dp → 16dp）
- 缩小字体（-10%）
- 隐藏次要信息
- 增加滚动区域

### 11.2 大屏幕适配 (6.1"-6.7")

**调整策略**：
- 增加内边距（24dp → 32dp）
- 增大字体（+10%）
- 显示更多信息
- 双列布局（统计页）
