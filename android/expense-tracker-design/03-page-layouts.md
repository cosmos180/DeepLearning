# 核心页面布局 (Page Layouts)

> **布局原则**: 信息密度适中、视觉层级清晰、操作效率优先
> **目标**: 3秒完成记账、一目了然的财务状况

---

## 1. 启动页 / 欢迎页 (Onboarding)

### 1.1 品牌启动页

**布局结构**:
```
┌─────────────────────────────┐
│                             │
│                             │
│         [LOGO]              │  40%
│                             │
│      个人日常消费记录         │
│                             │
│                             │
├─────────────────────────────┤
│  ✓ 3秒快速记账               │  60%
│  ✓ 智能分类自动识别           │
│  ✓ 本地存储隐私安全           │
│                             │
│  [开始使用] ──────────────>  │
│                             │
└─────────────────────────────┘
```

**设计要点**:
- **视觉中心**: Logo 居中，占屏幕上方 40%
- **价值主张**: 3 个核心卖点，简洁图标 + 短文案
- **行动按钮**: 全宽主按钮，不可错过的 CTA
- **背景色**: 渐变背景 (#EFF6FF → #DBEAFE)

**心理学应用**:
- 降低首次使用的焦虑感
- 建立信任和期待
- 明确产品价值

**布局结构**:
```
┌─────────────────────────────┐
│  [返回]          权限说明 1/3│

│       [图标]                │
│    相机权限                  │
```

**权限清单**:
1. 相机权限（扫描票据）
2. 通知权限（预算提醒）

**设计策略**:
- 说明为什么需要此权限（用户利益）
- 提供跳过选项（降低阻力）
- 一次只请求一个权限（降低认知负荷）
