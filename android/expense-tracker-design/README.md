# 账单通 (BillTrack) 产品设计文档

## 项目概述

账单通是一款专注于个人日常消费记录和分析的轻量级工具，通过简单快速的记录方式和直观的数据可视化，帮助用户建立健康的消费习惯，实现理性消费。

## 技术架构

### 技术栈

**移动端（Android）**：
- 语言：Kotlin
- 最低SDK：Android 7.0 (API 24)
- 架构：MVVM + Clean Architecture
- 数据库：Room
- 异步：Coroutines + Flow
- UI：Jetpack Compose
- 图表：MPAndroidChart
- 依赖注入：Hilt

### 系统架构

```
Presentation Layer (UI)
    ↓
Domain Layer (Business Logic)
    ↓
Data Layer (Repository + Database)
    ↓
Local Storage (Room Database)
```

## 用户画像

### 主要用户

1. **职场新人小李**（24岁，产品经理）
   - 月收入12,000元，月消费8,000元
   - 痛点：不知道钱花哪了，想要控制消费

2. **精打细算的张姐**（32岁，家庭主妇）
   - 负责家庭开支管理，月支出15,000元
   - 痛点：需要详细分类和报表功能

3. **大学生小王**（21岁，学生）
   - 月生活费2,500元，经常超支
   - 痛点：需要预算提醒和简单记录

## 核心用户流程

### 快速记账流程（3秒）
1. 点击"+"按钮（或摇一摇）
2. 输入金额
3. 选择分类
4. 自动保存

### 查看统计流程（1分钟）
1. 打开统计页
2. 查看本月支出概览
3. 浏览分类占比图
4. 分析主要支出类别
