# 色彩系统设计 (Color System)

> **设计理念**: 用色彩传达安全感、掌控感与激励
> **心理学基础**: 色彩心理学 × 文化联想 × 情感设计

---

## 1. 主色系 (Primary Colors)

### 1.1 核心主色: 深海蓝 (#2563EB)

**RGB**: rgb(37, 99, 235)
**HSL**: hsl(221, 83%, 53%)
**CMYK**: c(84) m(58) y(0) k(8)

**心理学解读**:
- **信任与可靠**: 蓝色是最受全球用户信赖的颜色，降低用户对财务产品的焦虑
- **冷静与理性**: 帮助用户做出理性的消费决策
- **专业与权威**: 传达产品的专业性和可靠性
- **安全与稳定**: 暗示数据的安全和隐私的保护

**应用场景**:
- 主要操作按钮（记账、保存）
- 导航栏激活状态
- 重要数据强调
- 品牌标识元素

**无障碍检查**:
- 与白色背景对比度: 8.2:1 ✅ (AAA级)
- 与浅灰背景对比度: 7.1:1 ✅ (AAA级)

### 1.2 主色变体系统

#### 浅色变体 (用于悬停、背景)
```css
--primary-50:  #EFF6FF  /* 浅背景 */
--primary-100: #DBEAFE  /* 次级背景 */
--primary-200: #BFDBFE  /* 禁用背景 */
--primary-300: #93C5FD  /* 分割线 */
--primary-400: #60A5FA  /* 悬停状态 */
--primary-500: #3B82F6  /* 标准主色 */
--primary-600: #2563EB  /* 深主色（默认） */
--primary-700: #1D4ED8  /* 按压状态 */
--primary-800: #1E40AF  /* 深色文本 */
--primary-900: #1E3A8A  /* 最深文本 */
```

**使用原则**:
- **50-100**: 大面积背景、卡片底色
- **200-300**: 悬停背景、轻量提示
- **400-500**: 次要按钮、标签
- **600-700**: 主要按钮、重要操作
- **800-900**: 标题、重要文本

## 2. 辅助色系 (Secondary Colors)

### 2.1 成功色: 翡翠绿 (#10B981)

**RGB**: rgb(16, 185, 129)
**HSL**: hsl(160, 84%, 39%)
**对比度**: 4.5:1 ✅ (AA级)

**心理学解读**:
- **成长与进步**: 象征财务健康和储蓄增长
- **积极强化**: 预算内的消费给予正面反馈
- **自然与健康**: 缓解金钱焦虑的心理压力
- **安全感**: 传达"在预算内"的安全信号

**应用场景**:
- 收入类型标识
- 预算内状态提示
- 节省金额高亮
- 正向数据趋势

**变体系统**:
```css
--success-50:  #ECFDF5
--success-100: #D1FAE5
--success-400: #34D399
--success-500: #10B981  /* 标准成功色 */
--success-600: #059669
--success-700: #047857
```

### 2.2 警告色: 琥珀橙 (#F59E0B)

**RGB**: rgb(245, 158, 11)
**HSL**: hsl(38, 92%, 50%)
**对比度**: 3.1:1 ⚠️ (仅用于大文本)

**心理学解读**:
- **温和提醒**: 不同于红色的紧迫感，橙色更友好
- **注意但不惊慌**: 预算接近临界点时的温和提示
- **活力与能量**: 激励用户调整消费行为
- **温暖与亲和**: 降低财务管理的焦虑感

**应用场景**:
- 预算预警（80%使用率）
- 待处理事项提示
- 需要关注的账单
- 数据异常提示

**变体系统**:
```css
--warning-50:  #FFFBEB
--warning-100: #FEF3C7
--warning-400: #FBBF24
--warning-500: #F59E0B  /* 标准警告色 */
--warning-600: #D97706
```

**使用原则**:
- 仅用于需要关注但不紧急的情况
- 避免大面积使用，防止视觉疲劳
- 搭配图标使用以增强可读性

---

### 2.3 危险色: 珊瑚红 (#EF4444)

**RGB**: rgb(239, 68, 68)
**HSL**: hsl(0, 79%, 60%)
**对比度**: 4.5:1 ✅ (AA级)

**心理学解读**:
- **紧急信号**: 预算超支的明确警示
- **损失厌恶**: 利用用户对损失的敏感性
- **行动触发**: 促使用户立即采取行动
- **边界设定**: 明确消费的安全边界

**应用场景**:
- 预算超支状态
- 删除操作确认
- 支出类型标识
- 负面数据趋势

**变体系统**:
```css
--danger-50:  #FEF2F2
--danger-100: #FEE2E2
--danger-400: #F87171
--danger-500: #EF4444  /* 标准危险色 */
--danger-600: #DC2626
--danger-700: #B91C1C
```

**使用原则**:
- **限制使用**: 仅用于真正需要立即注意的情况
- **降低焦虑**: 预算超支时提供解决方案，而非单纯警告
- **可操作**: 红色状态必须伴随可操作的按钮
- **避免过度**: 不要让用户感到被批评或羞耻

## 5. 分类色彩系统 (Category Colors)

为消费分类设计独特色系，便于快速识别和记忆：

```css
/* 餐饮美食 - 橙红色 */
--category-food: #F97316;

/* 交通出行 - 蓝色 */
--category-transport: #0EA5E9;

/* 购物消费 - 粉紫色 */
--category-shopping: #EC4899;

/* 居住生活 - 绿色 */
--category-housing: #22C55E;

/* 教育学习 - 靛蓝色 */
--category-education: #6366F1;

/* 医疗健康 - 红色 */
--category-health: #EF4444;

/* 休闲娱乐 - 黄色 */
--category-entertainment: #EAB308;

/* 人情社交 - 紫色 */
--category-social: #A855F7;

/* 投资理财 - 深绿色 */
--category-investment: #059669;
```

**设计原则**:
- 高饱和度，便于图标识别
- 色彩差异明显，避免混淆
- 与功能色区分，不产生歧义
- 支持色盲用户（通过形状辅助）

## 6. 深色模式色彩 (Dark Mode)

### 6.1 深色背景系统

```css
/* 深色模式背景 */
--dark-bg-primary: #111827;   /* 主背景 */
--dark-bg-secondary: #1F2937; /* 次级背景 */
--dark-bg-tertiary: #374151;  /* 三级背景 */

/* 深色模式文本 */
--dark-text-primary: #F9FAFB;   /* 主要文本 */
--dark-text-secondary: #D1D5DB; /* 次要文本 */
--dark-text-tertiary: #9CA3AF;  /* 三级文本 */
```

### 6.2 深色模式色彩调整原则

- **降低饱和度**: 避免在高对比度下产生视觉疲劳
- **提升亮度**: 确保在深色背景上清晰可读
- **保持层级**: 维持与浅色模式相同的视觉层级
- **减少眩光**: 避免纯白文字，使用略微偏暖的灰白色

## 7. 色彩无障碍标准 (Accessibility)

### 7.1 WCAG 2.1 AA 级标准

- **正常文本**: 对比度 ≥ 4.5:1
- **大文本 (18px+)**: 对比度 ≥ 3:1
- **UI 组件**: 对比度 ≥ 3:1

### 7.2 色盲友好设计

**色盲类型覆盖**:
- **红色盲 (Protanopia)**: 红色感知缺失
- **绿色盲 (Deuteranopia)**: 绿色感知缺失
- **蓝色盲 (Tritanopia)**: 蓝色感知缺失

**设计策略**:
1. **双重编码**: 颜色 + 图标/形状
2. **高对比度**: 确保色盲用户可区分
3. **模式验证**: 使用色盲模拟工具测试
4. **文本标签**: 关键信息不只依赖颜色

**示例实现**:
```css
/* 预算状态 - 色盲友好 */
.budget-safe {
  color: #10B981;
  border-left: 4px solid #10B981;
  background: url('icon-check.svg') no-repeat;
}

.budget-warning {
  color: #F59E0B;
  border-left: 4px solid #F59E0B;
  background: url('icon-alert.svg') no-repeat;
}

.budget-over {
  color: #EF4444;
  border-left: 4px solid #EF4444;
  background: url('icon-error.svg') no-repeat;
}
```

## 8. 色彩心理学应用案例

### 8.1 记账成功反馈

**场景**: 用户完成一笔消费记录

**设计**:
- 背景色: 浅绿 (#ECFDF5)
- 图标色: 成功绿 (#10B981)
- 微动画: 勾选图标从中心展开
- 心理效应: 正向强化，形成习惯回路

---

### 8.2 预算超支预警

**场景**: 月度预算超过 100%

**设计**:
- 避免纯红色背景（过于严厉）
- 使用浅红色背景 (#FEF2F2) + 红色图标
- 文案: "预算已用完，建议调整"（建设性 vs 批评性）
- 行动按钮: "查看详细" + "调整预算"
- 心理效应: 降低防御心理，促进问题解决

---

### 8.3 数据可视化配色

**场景**: 月度消费趋势图

**设计**:
- 上升趋势: 翡翠绿 (#10B981) - 正面（收入）
- 下降趋势: 珊瑚红 (#EF4444) - 负面（支出）
- 平稳趋势: 中性蓝 (#2563EB) - 稳定
- 预测线: 虚线 + 紫色 (#8B5CF6) - AI 预测

**心理效应**:
- 快速识别财务健康状态
- 颜色与直觉一致（绿=好，红=差）
- 降低数据分析的认知负荷

## 9. 色彩使用规范

### 9.1 比例控制

- **主色**: 60% (背景、基础元素)
- **辅助色**: 30% (强调、交互元素)
- **中性色**: 10% (文本、分割线)

### 9.2 禁忌组合

❌ **避免的组合**:
- 红色 + 绿色（色盲用户无法区分）
- 纯白 (#FFFFFF) + 纯黑 (#000000) - 眩光过强
- 高饱和度色 + 高饱和度色 - 视觉冲突
- 红色背景 + 蓝色文字 - 对比度不足

✅ **推荐组合**:
- 主色 + 白色背景
- 辅助色 + 浅灰背景
- 功能色 + 中性色
- 单一主色 + 多种中性色

```css
}
```
