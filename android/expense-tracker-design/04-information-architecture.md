## 1. 信息架构概述

本文档定义"账单通"产品的信息架构，包括页面层级结构、导航设计、内容组织和布局规范。

## 3. 导航架构

### 3.1 底部导航栏

**主导航**（首页、统计、记录、我的）：

```
┌──────────────────────────────────────────────────┐
│                                                  │
│                   内容区域                         │
│                                                  │
├────────────┬────────────┬────────────┬───────────┤
│  🏠 首页    │  📊 统计    │  📝 记录    │  ⚙️ 我的   │
└────────────┴────────────┴────────────┴───────────┘
```

**导航项说明**：

| 导航项 | 图标 | 标签 | 目标页面 | 功能 |
|--------|------|------|----------|------|
| 首页 | 🏠 | 首页 | Home | 统计概览、快速记账入口 |
| 统计 | 📊 | 统计 | Statistics | 图表分析、趋势查看 |
| 记录 | 📝 | 记录 | Transactions | 记录列表、搜索、管理 |
| 我的 | ⚙️ | 我的 | Settings | 设置、分类管理、数据管理 |

**交互状态**：
- 未选中：灰色图标 + 灰色文字
- 已选中：主题色图标 + 主题色文字
- 点击反馈：轻微缩放动画

---

### 3.2 辅助导航

#### 首页辅助导航
- **悬浮按钮**：右下角"+"按钮，触发快速记账
- **卡片点击**：统计卡片点击跳转到统计页
- **记录点击**：最近记录点击跳转到记录详情

#### 统计页辅助导航
- **时间选择器**：顶部下拉选择月份
- **Tab切换**：切换图表类型
- **图表点击**：钻取到分类详情

#### 记录页辅助导航
- **搜索按钮**：顶部搜索图标
- **筛选按钮**：筛选图标（后续版本）
- **记录项**：点击查看详情

#### 设置页辅助导航
- **列表导航**：点击各项进入子页面
- **返回按钮**：左上角返回

## 4. 页面详细设计

### 4.1 启动页 (Splash Screen)

**用途**：品牌展示、加载初始化

**元素**：
- 居中Logo（120x120px）
- 应用名称"账单通"（下方）
- Loading动画（底部）

**布局**：
```
┌─────────────────────────────┐
│                             │
│                             │
│                             │
│          [Logo]             │
│          账单通              │
│                             │
│                             │
│     ● ● ● ● ● (Loading)     │
│                             │
└─────────────────────────────┘
```

**持续时间**：2秒（可中断，加载完成立即跳转）

**内容元素**：

**1. 顶部栏**
- 左侧：应用名称"账单通"
- 右侧：通知图标（后续版本）

**2. 统计卡片**
- **本月支出卡片**（主卡片）：
  * 标题："本月支出"
  * 金额：大字体，主题色
  * 对比：与上月对比（箭头 + 百分比）
  * 预算进度：进度条 + 百分比（如果设置了预算）

- **今日/本周支出卡片**（次要卡片）：
  * 并排两个小卡片
  * 显示今日/本周支出
  * 与昨日/上周对比

**3. 分类排行**
- 标题："分类排行"
- 显示：前3名分类
- 每项：图标 + 分类名 + 金额 + 占比
- 右侧："查看更多"链接 → 跳转统计页

**4. 最近记录**
- 标题："最近记录"
- 显示：最近5条记录
- 每项：图标 + 分类 + 金额
- 点击：查看详情

**5. 悬浮按钮**
- 位置：右下角
- 图标：➕
- 尺寸：56x56dp
- 阴影：elevation 6dp
- 点击：弹出快速记账对话框

### 4.3 快速记账弹窗 (Quick Add)

**用途**：快速记录一笔消费

**布局结构**：
```
┌─────────────────────────────┐
│         记一笔    [×]       │ ← 标题栏
├─────────────────────────────┤
│                             │
│           ¥ 0.00           │ ← 金额输入
│                             │
├─────────────────────────────┤
│  选择分类                   │
│  ┌───┬───┬───┬───┬───┐   │ ← 分类选择
│  │🍔│🚇│👕│🎬│🏠│...│   │
│  │餐饮│交通│购物│娱乐│居住│   │
│  └───┴───┴───┴───┴───┘   │
│                             │
│  2025-01-16 今天 12:30  >  │ ← 日期时间
│                             │
│  ┌─────────────────────┐   │ ← 备注输入
│  │ 添加备注（可选）...   │   │
│  └─────────────────────┘   │
│                             │
│  💳 支付方式: 微信支付 >     │ ← 支付方式
│                             │
│  ┌─────────────────────┐   │
│  │        保存         │   │ ← 保存按钮
│  └─────────────────────┘   │
└─────────────────────────────┘
```

**内容元素**：

**1. 金额输入**
- 位置：屏幕中央，大字体
- 格式："¥ 0.00"
- 字体大小：48sp
- 点击：弹出数字键盘
- 实时格式化显示

**2. 分类选择**
- 标题："选择分类"
- 布局：横向滚动，每行5个
- 每项：图标（40x40dp）+ 分类名
- 高亮：选中项显示主题色背景
- 更多：点击"更多"查看所有分类

**3. 日期时间**
- 默认：当前日期和时间
- 格式："YYYY-MM-DD 今天 HH:mm"
- 点击：弹出日期时间选择器
- 快捷选项：今天、昨天

**4. 备注输入**
- 类型：单行文本输入
- 占位符："添加备注（可选）"
- 最多：50字
- 显示：剩余字数

**5. 支付方式**
- 默认：上次使用的支付方式
- 选项：微信支付、支付宝、现金、信用卡、其他
- 显示：图标 + 名称

**6. 保存按钮**
- 文本："保存"
- 样式：大按钮，主题色背景
- 点击：验证并保存

## 5. 内容组织原则

### 5.1 信息层级

**一级信息**（最重要）：
- 金额
- 分类
- 日期

**二级信息**（重要）：
- 备注
- 支付方式
- 时间

**三级信息**（辅助）：
- 创建时间
- 修改时间
- ID等系统字段

### 5.2 布局原则

1. **视觉焦点**：
   - 金额：大字体、主题色、居中
   - 操作按钮：显著位置、大尺寸
   - 重要数据：顶部显示

2. **阅读顺序**：
   - 从上到下、从左到右
   - 符合中文阅读习惯
   - 重要信息优先

3. **分组原则**：
   - 相关信息分组
   - 使用分隔线或间距
   - 提供分组标题

4. **空白使用**：
   - 适当留白，避免拥挤
   - 使用padding和margin
   - 保持视觉呼吸感

## 6. 响应式设计

### 6.1 屏幕尺寸适配

**小屏**（4.7"-5.5"）：
- 减少卡片内边距
- 缩小字体和图标
- 隐藏次要信息

**中屏**（5.5"-6.1"）：
- 标准布局
- 标准字体和图标

**大屏**（6.1"-6.7"）：
- 增加卡片内边距
- 增大字体和图标
- 显示更多信息

### 6.2 横屏适配

**支持横屏的页面**：
- 统计页：图表可以横屏查看
- 记录列表：可以横屏显示更多列

**不支持横屏的页面**：
- 快速记账弹窗
- 记录详情页
